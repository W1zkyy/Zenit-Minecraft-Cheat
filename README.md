# 📥 Запуск Zenith Client

Для старта игры нажмите кнопку **ЗАПУСТИТЬ** в главном меню лаунчера.

---

### ⚠️ Проверка обновлений

При обнаружении обновлений лаунчер выведет следующее уведомление:

> **У вас старая версия. Хотите обновить?**
> 👉 [Скачать обновление Zenith](https://github.com/W1zkyy/Zenith-Minecraft-Cheat)

---

### 🖥️ Интерфейс лаунчера

* 🚀 **ЗАПУСТИТЬ** — Старт актуальной версии чита.
* ⚙️ **Настройки** — Выбор папки с игрой и выделение ОЗУ.
* 🛠️ **Сброс HWID** — Сброс привязки к железу (для Premium).
